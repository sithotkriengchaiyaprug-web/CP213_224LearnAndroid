แอปช่วยบันทึกรายจ่ายอัตโนมัติ โดยไม่ต้องให้ผู้ใช้กรอกเอง🎯 Problem (ปัญหา)
คนส่วนใหญ่ “ไม่ทำบัญชีรายรับรายจ่าย” เพราะมันยุ่งยาก
แอปทั่วไปต้องให้กรอกเอง → คนขี้เกียจใช้
ไม่มีระบบช่วยคุม “งบรายวัน” แบบอัตโนมัติ
💡 Solution (แนวทางแก้)
แอปนี้จะ:
📩 ดึงข้อมูลรายจ่ายจาก notification ของธนาคารอัตโนมัติ
📸 ใช้ AI (OCR) สแกนสลิป (กดเองเท่านั้น)
📊 คำนวณ “งบที่เหลือในแต่ละวัน” แบบ real-time
📱 แสดงผลผ่าน Widget หน้า Home ไม่ต้องเปิดแอป
⚙️ แนวคิดระบบ (Architecture)
ใช้แนวทาง:
Clean Architecture + MVVM
→ แยกส่วนชัด ทำให้ดูเป็นโปรและขยายต่อได้

แบ่งเป็น 3 Layer:
UI Layer – หน้าจอ + Widget
Domain Layer – logic เช่น คำนวณงบ
Data Layer – database + notification + AI
🔑 Features หลัก
Auto Tracking (Zero-Touch)
อ่าน notification จากธนาคาร
ดึงจำนวนเงิน + ร้านค้า
Scan ใบเสร็จ (AI OCR)
ใช้ AI อ่านข้อมูลจากรูป
ระบบงบรายวัน
ตั้งงบ เช่น 100 บาท/วัน
เงินเหลือจะถูก carry ไปวันถัดไปWidgetดูเงินคงเหลือได้ทันที
